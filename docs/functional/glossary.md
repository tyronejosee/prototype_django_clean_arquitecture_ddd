# 📚 Glossary of Domain Terms

> [Disclaimer](../DISCLAIMER.md)

| Term             | Definition                                                                 |
|------------------|----------------------------------------------------------------------------|
| SKU              | Unique code that identifies a product in the inventory.                   |
| Product          | Item available for sale with attributes such as name, price, and stock.   |
| Category         | Classification that groups similar products.                              |
| Order            | Purchase request made by a customer that includes one or more products.   |
| Stock            | Available quantity of a product for sale.                                 |
| Discount         | Reduction applied to the base price of a product.                         |
| Customer         | User who buys products in the store.                                      |
| Administrator    | User who manages products, categories, and orders.                        |
| Order Status     | Stage in which an order is (Pending, Confirmed, Canceled, etc.).          |
| JWT              | Authentication token to secure API access.                                |
| Clean Architecture | Design pattern that separates responsibilities into independent layers. |
| DDD (Domain-Driven Design) | Methodology that focuses design on the domain and business rules.   |
